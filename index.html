A daily, read-only GitHub Action compares this snapshot with five machine-readable schedule sources — the MLB postseason Stats API and Westwood One's NFL, college football, college basketball and U.S. Soccer grids — and checks nine club, school, league and station pages (49ers, Cal, Stanford, Earthquakes, the KNBR 1050 grid, USF basketball and the NFL playoff pages) for changed text. Together that watches 151 of the 153 rows; the other two are games on the snapshot date itself. It opens or refreshes a review issue if any source changes or a check fails. A check that cannot complete is reported as unknown, never as “no drift”. The Action does not edit the feed, publish a new Pages snapshot, or confirm that a Bay Area station actually carried a game. Rebuild with python3 scripts/build_feed.py only after a fresh source review.
